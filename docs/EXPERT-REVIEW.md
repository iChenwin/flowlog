# FlowLog 流记：15 个 AI 专家角色的需求评审

日期：2026-10-21。以下为五个岗位、每岗三个 AI 专家角色的独立评审摘要与主导者综合决策。它们是 AI 角色评审，不代表邀请了 15 位真实从业者，也不是用户访谈或第三方认证。

## 独立意见

| 岗位与角色 | 主要意见 | 验收关注 |
| --- | --- | --- |
| 产品 1：日记工作流 | 今天优先、按日期倒序连续浏览；输入要顺畅 | Enter、Tab、撤销、多行粘贴与自动保存 |
| 产品 2：范围与取舍 | 安装包硬目标小于 20,000,000 字节，争取约 15 MB；先发布预览版 | 30 天日志、365 天与万块数据性能需测量 |
| 产品 3：迁移与保真 | 不应把打开笔记等同于重写；保留未知属性和 ID | 未编辑文件不变、复杂原文保留、外部修改冲突 |
| 设计 1：编辑交互 | 中文合成输入不得触发拆块；方向键跨块；反链可回到出处 | 中文输入法与焦点连续性需人工验证 |
| 设计 2：视觉层级 | 左侧约 208px、正文约 760px；暖白配蓝绿；16px/1.65 | 流式阅读密度、当前日期层级与窗口缩放 |
| 设计 3：可达与反馈 | 保存中、成功、失败应明确；键盘焦点可见；恢复可理解 | 仅键盘操作、错误提示、恢复草稿 |
| 销售 1：用户价值 | 服务以日常日志为主的个人用户；免费开源、三分钟上手 | 用户能快速写下首条记录并找到文件 |
| 销售 2：迁移信任 | 兼容和数据信任是主要阻碍；迁移前备份 | 三分钟演示 Enter、Tab、任务、双链、搜索及本地文件 |
| 销售 3：定位 | 使用独立品牌，描述为受 Logseq 启发 | 逐项兼容矩阵，不宣传完整复刻 |
| 技术 1：架构 | Tauri + Rust + 系统 WebView2；Markdown 为事实源 | 串行保存、原子替换、快照、内容哈希冲突 |
| 技术 2：编辑器 | 稳定块标识、子树移动、事务撤销；保留原文模式 | IME 不丢焦点、复杂语法保真、按日加载 |
| 技术 3：安全 | 笔记库路径边界、拒绝穿越及符号链接绕过；禁止原生 HTML | 哈希冲突、错误保留草稿、路径边界测试 |
| 运营 1：社区 | MIT、贡献与安全说明、问题模板、校验值 | 先预览发布，公开限制与反馈渠道 |
| 运营 2：发布质量 | 最终安装包体积门禁，构建与安装卸载冒烟 | 精确字节数、SHA-256、干净 Windows 与离线使用待验收 |
| 运营 3：新手体验 | 一分钟写首条；无需注册；提示快捷键与数据位置 | 优先修保存故障；反馈禁止附带私人笔记 |

## 综合决策与争议

1. 保留日记流、本地文件、大纲编辑、任务、页面链接、搜索和反链作为核心方向。v0.1 定位为预览版本，具体已实现项目以 README 和代码为准。
2. 裁掉图谱可视化、白板、PDF 标注、插件系统、云同步和复杂查询。减少组件与安装包大小，同时收窄首版验收范围。
3. 产品 1 将块引用排在后续优先级，设计 1 倾向完整编辑体验。最终块引用与完整 Logseq 编辑语义留待后续，避免首版过度扩张。
4. 原地编辑的便利与 Markdown 保真存在冲突。复杂 Markdown 应保留原文编辑方式；首版推荐在笔记库副本上试用，禁止将部分语法支持称为完整兼容。
5. 系统 WebView2 帮助缩小安装包，但带来运行时依赖。必须公开依赖，并区分安装包大小与用户环境需要补装的体积。

## 验收与证据边界

自动门禁：类型检查、单元测试、Rust 测试、Windows 构建、NSIS 安装包小于 20,000,000 字节、SHA-256、安装卸载冒烟。具体结果以对应 CI 运行及报告为准。

仍需人工验证：中文输入法组合输入、连续长时间记录、仅键盘导航、干净 Windows 安装、断网首次启动、升级和真实 Logseq 副本迁移。专家意见或加入 CI 配置不等于这些检查已经通过。

完整清单见 [发布验收](RELEASE-CHECKLIST.md)。发布者应明确区分“已实现”“自动验证通过”“人工验证通过”和“待验证”。
