# 0.2.0 Windows 原生版验证

日期：2026-10-21。本页与 0.1 WebView 原型的验证记录分开。原生版为 C#5 / WPF / AvalonEdit 6.3.1.120，目标系统 .NET Framework 4.8。公开构建见 [Windows native 工作流](https://github.com/iChenwin/flowlog/actions/workflows/windows-native.yml)，发布附件提供包体积、校验值和跨进程验证报告。

## 已执行的本机验证

系统 Windows 10 build 19045，真实 .NET Framework 可执行文件，未通过浏览器或模拟 DOM 测试。`scripts/build-native.ps1 -Tests` 实际通过 **113 项检查**：

| 范围 | 检查数 | 主要证据 |
| --- | ---: | --- |
| 本地存储 | 23 | UTF-8/BOM/CRLF、原文往返、相同内容不重写、备份限额、外部冲突双方、草稿恢复、特殊及长标题、路径边界、非法编码拒绝 |
| 原生编辑器 | 60 | 拆块与换行、选区、缩进/子树移动、无末尾换行、撤销重做、折叠状态、持久 UUID、补全、代码围栏、源码模式、同层拖动事件路由 |
| 原生窗口 | 30 | 真实控件输入、即时草稿、异步保存、导航保留选区与撤销、7日日记增量加载、关窗等待保存、重开恢复、冲突不覆盖、搜索/任务/页面、深色主题 |

窗口测试使用真实 WPF 控件、VisualTree 和 `TextArea.PerformTextInput`；测试内的“重开窗口”指重建窗口实例。截图使用实际 WPF 可视树渲染，不是设计稿。

`scripts/smoke-native.ps1 -Installed` 另外执行**跨操作系统进程**验收，实际通过：

1. 静默安装用户目录，无需管理员权限。
2. 启动安装后的 EXE，通过 Windows UIAutomation 找到原生文档控件。
3. 原生 ValuePattern 设置中文/emoji 多行内容，验证真实 Markdown 字节内容。
4. 通过 WindowPattern 关闭，启动新进程，读取并核对文档。
5. 修改后强制结束本测试启动的进程，重启核对最后内容及恢复落盘。
6. 文件被外部修改后再次编辑，确认磁盘保留外部内容，`.flowlog/conflicts` 保留双方。
7. 在冲突状态再次强制结束及重启，确认恢复本地草稿并保留外部磁盘内容。
8. 检查实际进程已加载 WPF，未加载 WebView/Chromium/Electron 模块。
9. 卸载应用，确认笔记文件仍在且内容不变。

所有笔记均为隔离测试目录中的虚构数据。UIAutomation 的 ValuePattern 用于验证应用和文件管道，不代表模拟了真人逐键输入；编辑事务及选区另由原生编辑器测试覆盖。报告中记录小样例的进程内存，不能推断大库性能。

## 包体积与运行环境

本机构建安装包 **288,302 字节**、便携 ZIP **267,197 字节**，均小于 20,000,000 字节。CI 的编译器/时间戳会使具体二进制及压缩体积不同，下载时以同一发布附件 `native-package-report.json` 的字节和 SHA-256 为准。

生产包只包含程序、AvalonEdit DLL、配置和许可证，不包含测试程序、旧网页前端或 Rust 程序。系统 **.NET Framework 4.8** 不计入包体积；安装器检查该系统依赖，缺少时中止并提示补装。未在缺少运行时的干净系统实测安装。未提供代码签名或自动更新。

## 尚未人工验收

- 微软拼音及其他中文输入法的候选窗、确认键、长句连续合成；自动测试只验证输入事件保护及取消恢复。
- 物理鼠标的完整 OLE 拖动链路；目前验证专用手柄、真实坐标/原生拖动事件路由、同层重排、撤销与折叠保持。跨层拖动不提供。
- 屏幕阅读器、完整仅键盘体验、触屏、高 DPI 多屏和长期剪贴板使用。
- 干净 Windows 10/11、首次离线安装、不同系统语言、升级及长期编辑。
- 365 天/万块以上数据的延迟和内存，真实历史 Logseq 库的完整迁移。
- 断电、磁盘写满、网络盘、同步软件竞争、所有保存阶段的终止恢复。

本次跨进程强杀测试只覆盖具体执行时间点，不能证明所有竞争窗口。存储算法及兼容限制见 [架构说明](NATIVE-ARCHITECTURE.md)。本版不宣称完整复刻 Logseq，也不将 AI 专家角色讨论等同于第三方验收。
